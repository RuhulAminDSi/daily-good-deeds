# Typography

## 1. Font selection

| Script | Font | Fallback stack | Source |
|---|---|---|---|
| Latin (EN UI) | **Inter** (variable, wght 400–700) | `system-ui, -apple-system, "Segoe UI", Roboto, sans-serif` | Self-hosted via `next/font/google` (no runtime request to Google) |
| Bengali (BN UI) | **Hind Siliguri** (400, 500, 600, 700) | `"Noto Sans Bengali", "Nirmala UI", "Vrinda", sans-serif` | Self-hosted via `next/font/google` |
| Arabic (Quran, Dua, Dhikr text) | **Amiri Quran** for Quranic āyāt; **Amiri** for duas/dhikr | `"Noto Naskh Arabic", "Traditional Arabic", serif` | Self-hosted |
| Numerals in data (tables, counters) | Inter with `font-variant-numeric: tabular-nums` | — | — |

### Why Hind Siliguri over Noto Sans Bengali
| Criterion | Hind Siliguri | Noto Sans Bengali |
|---|---|---|
| Designed for UI / screen text | Yes. Optimised for UI with open counters. | Yes |
| Visual harmony with Inter | **Better.** Similar x-height and stroke contrast; looks consistent in mixed EN/BN strings. | Slightly narrower, with heavier conjuncts |
| Conjunct (যুক্তাক্ষর) and reph/vowel-sign rendering | Correct in Chromium, Firefox, and Safari | Correct (most complete glyph coverage) |
| File size (subset, 4 weights) | ~ 220 KB total | ~ 300 KB+ (variable) |
| Familiarity for Bangladeshi users | Widely used on BD web products | Common as an Android system font |

**Decision:** Hind Siliguri is the primary Bengali face. Noto Sans Bengali is the first fallback, because Android in-app webviews already ship it, so text still renders well before the web font loads. Rare-glyph tests in Phase 2 must confirm conjuncts such as ক্ষ, জ্ঞ, ন্ত্র, and হ্ম render correctly. If any glyph fails, swap the order.

### Arabic font note
- **Amiri Quran** is designed for Quranic typesetting: correct marks for waqf, sajdah, and small high letters. It is open source (OFL).
- **KFGQPC Uthmanic Script (Hafs)** is the canonical Madinah Mushaf font. Its licence allows free distribution but forbids modification. If the content reviewer prefers the Madinah mushaf look, it can be used for āyāt **as-is**, with no subsetting that alters the glyph set. Decision deferred to Phase 5 content review (tracked in DECISION_LOG).
- Arabic text is **never** generated by AI and is never rendered from user input in an Arabic-styled block.

| Token | Size / line-height EN | Line-height BN | Weight | Use |
|---|---|---|---|---|
| `text-display` | 2.25rem / 1.2 | 1.35 | 700 | Landing hero only |
| `text-h1` | 1.75rem / 1.25 | 1.4 | 700 | Page title |
| `text-h2` | 1.375rem / 1.3 | 1.45 | 600 | Section title |
| `text-h3` | 1.125rem / 1.35 | 1.5 | 600 | Card title |
| `text-body` | 1rem / 1.5 | **1.7** | 400 | Body |
| `text-body-sm` | 0.875rem / 1.45 | **1.65** | 400 | Secondary text, table cells |

| `text-label` | 0.875rem / 1.3 | 1.5 | 500 | Form labels, buttons |

On mobile (< 640px), `h1` steps down to 1.5rem and `display` to 1.875rem.

## 3. Bengali-specific rules
1. **Line height:** Bengali has tall ascenders (মাত্রা line plus upper vowel signs ি ী ৈ ৌ) and descenders (ু ূ ৃ). BN line heights are **+0.15 to +0.2** above EN. Apply them with `:lang(bn)` selectors, never with per-component overrides.
2. **No letter-spacing** on Bengali text. Tracking breaks the headline (মাত্রা) joins. Uppercase transforms and `letter-spacing` utilities are disabled under `:lang(bn)`.
3. **No faux bold or italic.** Bengali has no italic style. Use weight or colour for emphasis.
4. **Truncation:** BN strings average about 15–30 % longer than EN. Use `line-clamp` (2 lines) rather than single-line ellipsis for titles. Buttons must never truncate; let them wrap.
5. **Minimum size:** 13px for any Bengali text, including captions and chart labels.
6. **Mixed-script strings** (for example "আজ 3টি good deeds"): set `lang` on the inner `<span>` so the correct font and line-height are applied.

## 4. Numerals
- User preference `user_preferences.numeral_system`: `latn` (0-9) or `beng` (০-৯). The default is `beng` when the locale is BN and `latn` when it is EN.
- All numbers, dates and times are formatted with the helpers in `@dgd/i18n` (`formatNumber`, `formatDate`, `formatTime`, `formatRelative`, `formatHijri`, `formatCode`). They take `{ locale, numerals, timeZone }` and set the digit system as a locale extension (`bn-BD-u-nu-beng`). Never call `.toString()` on a user-visible number.
- Bengali grouping uses the Indian system (১২,৩৪,৫৬৭) via `bn-BD`.
- **Exceptions that always use Latin digits:** OTP/TOTP codes, IDs, and timestamps in admin audit logs. This avoids ambiguity when the value is copied.
- Arabic āyah numbers inside Quran text use the Arabic-Indic glyphs supplied by the Quran source (e.g. ﴿١٢﴾).

## 5. Dates & calendars
- Dates use `Intl.DateTimeFormat` with the user's locale and IANA timezone. BN month names use the Gregorian calendar (জানুয়ারি …). The Bengali calendar (বঙ্গাব্দ) is a **Could** item and is not in the registry yet. It is recorded in FUTURE_ENHANCEMENTS.
- Hijri dates use `Intl.DateTimeFormat(locale + '-u-ca-islamic-umalqura')` plus the user's day offset (F-ISL-013), shown as a secondary line under Gregorian dates where the Islamic module is enabled.

## 6. Arabic / RTL handling
- The app UI is **LTR only** (EN, BN). Arabic appears only in content blocks.
- Every Arabic block is rendered as `<p lang="ar" dir="rtl" class="text-arabic">`, wrapped in a container with `unicode-bidi: isolate`, so surrounding LTR layout is not affected.
- Transliteration (EN) and translation (EN/BN) follow underneath in the UI language, each with a source citation line (F-ISL-018).
- The `font-feature-settings` defaults of Amiri Quran must not be overridden. Do not apply `text-transform`, `letter-spacing`, or `word-spacing`.
- Screen readers: Arabic blocks carry `lang="ar"` so a voice that supports Arabic is used. A visible "Show translation" toggle is provided for users without Arabic voices.

## 7. Loading strategy
- `next/font` with `display: swap` and `adjustFontFallback` keeps layout shift close to zero.
- Only the UI-language font is preloaded. Arabic fonts load lazily on Islamic pages.
- Subsets: Latin plus Latin-ext for Inter; Bengali for Hind Siliguri; Arabic for Amiri. Budget for the first load: **≤ 120 KB of fonts** for either locale.
