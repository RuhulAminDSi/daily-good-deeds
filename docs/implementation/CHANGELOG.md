### Added (2026-10-30), Phase 2: T-P2-PLAT-001 monorepo scaffold
- pnpm 10.34.9 (pinned in `packageManager`, via Corepack) and Turborepo 2.11.10, with build, lint, typecheck, test, e2e and dev pipelines.
- `packages/config`: TypeScript 6.0.3 presets (base, node, react), an ESLint 10 flat config (typescript-eslint 8.72, Prettier-compatible), and a Prettier preset.
- `.editorconfig`, `.gitattributes` (LF, RISK-017), `.nvmrc` (Node 24) and `.prettierignore`.
- Moved the doc generators into `tools/docs/` (`pnpm docs:gen`). `task-status.json` drives the tracker's Status column.
- Verified: a clean `pnpm install --frozen-lockfile` and `turbo run build lint typecheck test` pass on Windows. Prettier check passes. Linux CI verification is pending (T-P2-PLAT-007).
- Version note: TypeScript 7 is out, but typescript-eslint supports only versions below 6.1, so TypeScript is pinned to 6.0.3. Prisma "latest" is an 8.0 RC, so the stable 7.x line will be used.

### Changed (2026-10-30): pre-push review of the scaffold
- **Doc tooling:** `tools/docs` is now the `@dgd/docs-tools` workspace package (ESM, linted).
  - One shared `lib.js` parses the registry, SRS, task status and test-case allocation. The duplicated parsers and allocator are gone.
  - The traceability step reads `tasks.js` directly instead of scraping the generated tracker.
  - New `pnpm docs:check` (turbo `check` task) fails on stale generated docs or integrity gaps.
  - P0 and P1 statuses moved into `task-status.json`. P1 is now Done after approval.
- **SRS §19 sync table:** added the Feature and Priority columns, so `FR-PWA-006-11…18` are traced and linked from TC-PWA-006-01.
- **Config cleanup:**
  - ESLint base is now environment-neutral and uses `defineConfig`. Node globals moved to a new `eslint/node` preset.
  - Removed settings that only restated defaults (TS, Prettier, ESLint, turbo, pnpm).
  - turbo: lint, typecheck and test no longer wait on upstream builds. `NODE_ENV` is scoped to build.
  - `.prettierignore` is root-anchored (`/docs/`), so `tools/docs` is formatted again.
  - Node engines are pinned to `^24`.
  - The root README has setup steps.
