# Data Dictionary

> Status: Specification. This is the source for the Prisma schema in Phase 2+. Read it alongside [DATABASE_DESIGN.md](DATABASE_DESIGN.md).

## 0. Conventions

- **Null:** `N` means NOT NULL, `Y` means nullable.
- **std** stands for these three standard columns:
  - `id uuid N` PK. A UUIDv7 generated by the application.
  - `created_at timestamptz N DEFAULT now()`
  - `updated_at timestamptz N DEFAULT now()`, maintained by Prisma `@updatedAt`
- **std-ro** is std without `updated_at`, for append-only tables.
- **sync** stands for the columns on syncable rows (DATABASE_DESIGN §8, DL-015):
  - `change_seq bigint N DEFAULT nextval('change_seq_global')`, which is bumped on every insert, update and soft delete by a trigger and is the delta-pull cursor
  - `client_updated_at timestamptz Y`, the client time used by the row-level last-writer-wins rule
  - `deleted_at timestamptz Y`, the tombstone
- **Table counts and phases** are listed only in [docs/README.md §6](../README.md). Section headings here carry no counts.
- Every `user_id` FK points to `users(id)` with `ON DELETE CASCADE` unless a table says otherwise.
- Translatable tables use a composite PK `(parent_id, locale)` with a `locale locale_code` column.
