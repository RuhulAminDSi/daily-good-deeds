# @dgd/api-client

A typed client for the Daily Good Deeds API, built on [openapi-fetch](https://openapi-ts.dev/openapi-fetch/).

These files are **generated by the API** from its real routes. Don't edit them:

- `openapi.json`
- `src/schema.ts`

After changing API routes or response schemas, regenerate them:

```sh
pnpm --filter @dgd/api openapi
```

The API's test suite fails when either file is stale (`test/openapi.spec.ts`).

The hand-written schemas live in `@dgd/contracts` (Zod). This package only contains what is derived from them.
